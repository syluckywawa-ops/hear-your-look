# 听见妆容 · Hear Your Look

面向低视力用户的美妆辅助交互原型。当前以口红检查、语音提示、修正和复查的演示流程为主。

## 文件

- `index.html`：网页入口及方案介绍。
- `style.css`、`polish.css`：页面样式、响应式布局和无障碍显示模式。
- `app.js`：预设演示流程、摄像头预览与语音播报。
- `polish.js`：语速、高对比度和专注模式控制。

## 预览与上传

这是纯静态网页，不需要安装依赖或构建。保持以上五个文件在同一个目录。

解压后可打开 `index.html` 查看页面。摄像头功能需要浏览器许可，建议在 HTTPS 网站或 localhost 环境体验；本地直接打开文件时，各浏览器支持情况可能不同。

上传 GitHub 时，请上传解压后的文件，而不是只上传 ZIP。将 `index.html` 和其他网页文件放在仓库根目录，随后配置 GitHub Pages，才会获得可直接浏览的网页链接。仅上传代码不会自动开通网页。

## 当前能力与限制

- 提供预设的检查、修正、复查情景，以及大字、高对比度、专注模式和可调语速。
- 摄像头仅用于本地实时预览，当前代码不上传画面。
- 检测结果来自预设情景，不是真实视觉识别结果。
- 语音播报使用浏览器能力，实际可用语音取决于设备；尚未实现语音指令识别。
- 尚未完成真实用户效果验证，不应将演示结果作为准确率或实际产品效果证明。

本压缩包不包含账号配置、内部部署配置、Git 历史或访问名单。
