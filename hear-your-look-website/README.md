# 听见妆容 · Hear Your Look

面向有基础化妆经验的低视力用户的口红唇线检查参赛原型，非赛事官方产品。

## 在线体验

[打开完整版本](https://hear-your-look.onrender.com/#studio)。网页与实验性 AI 检查均免登录；默认仍为预设演示，真实检查需主动选择并逐张同意发送照片。

Render 免费实例闲置后可能需要约一分钟唤醒。额度不足或服务失败会明确提示，不会静默切换到演示结果。

## 当前能力

准备照片 → 判断画面质量 → 观察明显口红外溢 → 用户自身左右定位与单步指引 → 新照片复查 → 自主结束。

- 演示模式不发送照片，结果来自预设，不是图片识别证据。
- 真实模式使用 OpenRouter / `google/gemini-2.5-flash`，先判断入镜、清晰度、光照、遮挡，再分析外溢。模型判断可能出错，能力尚未系统验证。
- 需确认照片是否镜像；网页摄像头拍摄标为原始方向。每张照片需要重新发送同意。
- 复查仅观察新照片，不比较前后效果，不宣称改善。
- 支持上传、摄像头倒计时、大字、高对比度、暂停、重听与浏览器语音。尚未完成完整 WCAG、真实移动设备、读屏及目标用户验收。

## 本地运行与部署

在仓库根目录配置被忽略的 `.env.local`（模型密钥仅在服务端），运行 `python3 start.py`；Mac 也可使用根目录启动脚本。详见 [配置说明](../OPENROUTER_SETUP.md) 与 [部署说明](../DEPLOYMENT.md)。

仅演示可在本目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`，浏览器打开 `http://localhost:8000`；静态服务不能执行真实 AI。

网页为 HTML/CSS/JavaScript；公开服务使用 Flask/Gunicorn 与 Upstash 持久限额。当前配置每日最多 20 个模型调用额度单位，每次检查保守预留 2 个；全站每分钟最多 3 次检查、单任务并发。不设置累计美元上限，仍可能消耗 OpenRouter 余额。

## 隐私与安全

真实照片最长边缩小至 1600px 并重新编码，经项目服务端发送至 OpenRouter 和模型提供商。项目服务端不落盘保存照片；外部处理与留存受供应商政策约束。结束体验释放浏览器照片与摄像头，不能撤回此前发送的照片。

密钥仅存服务端环境变量，不得提交 `.env.local`、令牌或密码。真实接口保留来源检查、CSRF、发送同意与共享限额；额度存储不可用时拒绝模型调用。

[最新线上合成照片测试及修复报告](../validation/线上照片模型测试报告_2026-10-07.md)。修复后的外溢、正常、模糊样本线上复测符合预期；遮挡样本在本地真实调用中安全拒绝。50 项 Python 测试与 10 项前端结果校验通过。

小样本合成照片测试不代表模型总体准确率，也不替代低视力用户研究。旧版预设测试保留为历史记录，不得当作当前模型效果。
